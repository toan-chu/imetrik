# Repository snapshot

iMetriK is an offline, static browser dashboard built with vanilla JavaScript and locally vendored libraries. The app launches from `index.html` without a build step or server requirement.

## Active structure

- `src/` - application data, model, query, view, i18n, and report modules.
- `vendor/`, `fonts/`, `assets/` - locally bundled runtime dependencies and brand assets.
- `tests/` - static and runtime smoke checks.
- `handoff/tasks/` - one lifecycle file per active or completed task.
- `log/rules.md` - standing project rules.
- `log/sessions/` - one journal file per completed session.
- `memory/source/` - human-curated, read-only source material.
- `memory/semantic/`, `memory/procedural/` - project facts and durable workflows with provenance.
- `memory/episodic/` - append-only runtime traces.

## Historical material

Superseded build prompts, handoffs, and the closed v1 blueprint are preserved unchanged under `memory/source/legacy/`. They are historical context, not active instructions.
